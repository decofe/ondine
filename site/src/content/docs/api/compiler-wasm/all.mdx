# ondine/compiler/wasm/all

The size-optimized compiler module for every diagram type, inlined as base64.

`ondine/compiler/wasm/all` exports one value, `wasm`, for [`create`](/docs/api/compiler/create). The entrypoint is about 715 kB gzip. Thus a page loads it with a dynamic import only when the page needs a compiler.

```ts title="preview.ts"
import { create } from 'ondine/compiler/wasm'

// Downloads the module only when the preview opens
const { wasm } = await import('ondine/compiler/wasm/all')
const renderer = create({ modules: { all: wasm } })
```

## Exports

### wasm

- **Type:** `string{:ts}`

The bytes of the module as base64. `create` compiles them synchronously at the first render.

```ts
import { create } from 'ondine/compiler/wasm'
import { wasm } from 'ondine/compiler/wasm/all'

// Registers the module under the key `all`
create({ modules: { all: wasm } })
```

Some hosts, such as Cloudflare Workers, do not allow compilation at runtime. These hosts cannot compile these bytes. On such a host, pass a precompiled `WebAssembly.Module` to `create`.
