# ondine/compiler

Render Mermaid to SVG in Node, build tools, and servers.

`ondine/compiler` loads the speed-optimized compiler module for every diagram type from the files of the package. This entrypoint uses the Node filesystem. Browsers and Workers use [`ondine/compiler/wasm`](/docs/api/compiler-wasm) instead.

```ts title="build.ts"
import { render } from 'ondine/compiler'

// Compiles synchronously
const { svg } = render('flowchart LR\n  A --> B')
```
