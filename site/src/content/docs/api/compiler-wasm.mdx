# ondine/compiler/wasm

Compile Mermaid in browsers and edge runtimes with modules supplied by the caller.

`ondine/compiler/wasm` contains the JavaScript glue (about 1 kB gzip) and no WebAssembly. The caller passes modules to `create`, such as the module from `ondine/compiler/wasm/all`. The [In-Browser Compilation](/docs/guides/browser) guide shows common tasks.

```ts title="preview.ts"
import { create } from 'ondine/compiler/wasm'
import { wasm as all } from 'ondine/compiler/wasm/all'

// Compiles a flowchart in the browser
const { svg } = create({ modules: { all } }).render('flowchart LR\n  A --> B')
```
