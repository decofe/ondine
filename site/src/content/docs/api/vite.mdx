# ondine/vite

Compile Mermaid file imports to SVG during the Vite build.

The `ondine/vite` entrypoint exports one Vite plugin. The plugin requires Vite as a peer dependency. It compiles with the same module as `ondine/compiler`. The [Vite](/docs/guides/vite) guide shows common tasks.

```ts title="vite.config.ts"
import { defineConfig } from 'vite'
import { ondine } from 'ondine/vite'

export default defineConfig({
  // Compiles .mmd and .mermaid imports
  plugins: [ondine()],
})
```
