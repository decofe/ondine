# ondine/vite

Compile Mermaid file imports to SVG during the Vite build.

`ondine/vite` exports one Vite plugin. It requires Vite as a peer dependency and compiles with the same module as `ondine/compiler`. The [Vite](/docs/guides/vite) guide covers common tasks.

```ts title="vite.config.ts"
import { defineConfig } from 'vite'
import { ondine } from 'ondine/vite'

export default defineConfig({
  // Compiles .mmd and .mermaid imports
  plugins: [ondine()],
})
```
