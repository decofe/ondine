# create

Create a renderer over compiler modules supplied by the caller.

`create` is exported from `ondine/compiler/wasm` and `ondine/compiler`. Each module holds one diagram type, or `all` of them, as a compiled `WebAssembly.Module` or base64 bytes. The [In-Browser Compilation](/docs/guides/browser) guide covers common tasks.

```ts title="preview.ts"
import { create } from 'ondine/compiler/wasm'
import { wasm as all } from 'ondine/compiler/wasm/all'

// Instantiates the module on the first render
const renderer = create({ modules: { all } })
const { svg } = renderer.render('flowchart LR\n  A --> B')
```

## Signature

```ts
// A renderer that instantiates each module once, on first use
create(options)
```

## Parameters

### options.modules

- **Type:** `Readonly<Record<string, WebAssembly.Module | string>>{:ts}`

WebAssembly modules by diagram type, as compiled modules or base64 bytes. Base64 bytes compile synchronously on first use. Hosts that refuse runtime compilation, such as Cloudflare Workers, pass a module their bundler compiled.

```ts
import { create } from 'ondine/compiler/wasm'
import all from 'ondine/compiler/wasm/all.wasm'

// Passes a module compiled ahead of time by the bundler
const renderer = create({ modules: { all } })
```

The renderer sends source to the first module. When that module reports a type it does not include, the renderer retries with the module registered under that type.

## Returns

### render

- **Type:** `(source: string, options?: render.Options) => render.ReturnType{:ts}`

Renders `source` with the module for its diagram type. It takes the same options and returns the same result as [`render`](/docs/api/compiler/render) from `ondine/compiler`.

```ts
import { create } from 'ondine/compiler/wasm'
import { wasm as all } from 'ondine/compiler/wasm/all'

const renderer = create({ modules: { all } })

// Lays out for the preview's width
renderer.render('flowchart LR\n  A --> B', { maxWidth: 480 })
```

## Errors

### Error

`render` throws a plain `Error` with the message `Render.create needs at least one module.` when `modules` is empty.

```ts
import { create } from 'ondine/compiler/wasm'

// Throws on the first render
create({ modules: {} }).render('flowchart LR\n  A --> B')
```

### RenderError

`render` throws a [`RenderError`](/docs/api/compiler/RenderError) when the source cannot be rendered, including when no supplied module includes its diagram type.
