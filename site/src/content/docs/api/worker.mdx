# Image Worker

Serve diagrams as SVG images from a Cloudflare Worker, for Markdown hosts such as GitHub.

The Worker at `https://ondine.sh` compiles the Mermaid source encoded in the request path with every diagram type. It ships with the documentation site in `site/`, and its compiler module is precompiled at build time, so requests download nothing. The [GitHub Images](/docs/guides/github) guide covers common tasks.

```md title="README.md"
<!-- Renders a two-node flowchart that follows the reader's scheme -->

![Flow](https://ondine.sh/eJxLy8kvT85ILCpR8AniUlBwVNDVtVNwAgBUvQYu.svg)
```

## Request

```txt
GET /<payload>.svg?scheme=light|dark
GET /svg?source=<source>&scheme=light|dark
GET /<payload>.png
GET /png?source=<source>
```

`HEAD` is also accepted. Other methods return `405` with an `allow: GET, HEAD` header, and other paths return `404`.

### payload

- **Type:** base64url string

The Mermaid source as UTF-8, deflated with zlib, then encoded as base64url without padding.

```ts
import * as Zlib from 'node:zlib'

// Encodes a diagram for the request path
const payload = Zlib.deflateSync('flowchart LR\n  A --> B').toString('base64url')
```

### source

- **Type:** percent-encoded string

The Mermaid source in the query of `/svg`, for authors and agents that cannot deflate. URLs grow faster than with a payload.

```md
<!-- Renders a two-node flowchart from plain source -->

![Flow](https://ondine.sh/svg?source=flowchart%20LR%0A%20%20A%20--%3E%20B)
```

### scheme

- **Type:** `'light' | 'dark'{:ts}`

Pins one color scheme. Without it, the image switches with `prefers-color-scheme`.

```html
<!-- Shows the dark variant when GitHub uses a dark theme -->
<picture>
  <source
    media="(prefers-color-scheme: dark)"
    srcset="https://ondine.sh/<payload>.svg?scheme=dark"
  />
  <img alt="Flow" src="https://ondine.sh/<payload>.svg?scheme=light" />
</picture>
```

## Response

### PNG Cards

The `.png` and `/png` forms draw the diagram on a 1200x630 card in the light scheme, sized for link previews. Link previewers such as Slackbot that request an SVG address receive an HTML page whose `og:image` is the card.

```md
<!-- Shows the diagram where SVG images are not displayed -->

![Flow](https://ondine.sh/png?source=flowchart%20LR%0A%20%20A%20--%3E%20B)
```

### Success

Status `200` with the compiled SVG. A `<style>` element after the root tag sets `--ondine-bg`, `--ondine-fg`, and `--ondine-line` for the scheme, since images cannot inherit page styles.

| Header                    | Value                                                  |
| ------------------------- | ------------------------------------------------------ |
| `cache-control`           | `public, max-age=86400, stale-while-revalidate=604800` |
| `content-security-policy` | `default-src 'none'; style-src 'unsafe-inline'`        |
| `content-type`            | `image/svg+xml; charset=utf-8`                         |
| `x-content-type-options`  | `nosniff`                                              |

### Errors

Status `400` with an SVG card that reads "Ondine could not render this diagram." followed by the error message, cached for 300 seconds.

| Cause                               | Message                                  |
| ----------------------------------- | ---------------------------------------- |
| Path or query over 4,096 characters | `Payload exceeds 4096 characters.`       |
| `/svg` without `source`             | `The source query parameter is missing.` |
| Invalid base64url                   | `Payload is not base64url.`              |
| Invalid zlib data or UTF-8          | `Payload is not zlib-deflated UTF-8.`    |
| Source over 64 KiB after inflating  | `Source exceeds 65536 bytes.`            |
| Invalid Mermaid                     | The `RenderError` message                |

## Deploy

```sh
# Builds the site, including the image route, and deploys it with Wrangler
pnpm --dir site run deploy
```
