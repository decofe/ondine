# Concepts & Principles

The model behind Melee: where diagrams compile, how they are measured, and what the output guarantees.

## Overview

Melee splits into a compiler and a runtime. The compiler is Rust built to WebAssembly, and turns Mermaid source into an SVG document. The runtime inserts that document into a page.

```mermaid
flowchart TB
  source[Mermaid source] --> pre[Preprocess]
  pre --> parse[Parse]
  parse --> model[Diagram model]
  model --> layout[Layout]
  layout --> emit[SVG]
```

## Compile Targets

The compiler ships as WebAssembly in two profiles. Node, the CLI, and the image Worker load one module optimized for speed. Browsers load a module optimized for size from `melee/compiler/wasm/all`.

| Entrypoint            | Runs in           | Module                    |
| --------------------- | ----------------- | ------------------------- |
| `melee/compiler`      | Node              | Every type, speed profile |
| `melee/vite`          | Vite builds       | Every type, speed profile |
| `melee` CLI           | Node              | Every type, speed profile |
| `melee/compiler/wasm` | Browsers, Workers | Supplied by the caller    |
| `melee`               | Browsers          | None                      |

> [!NOTE]
> The build also produces one size-optimized module per diagram type, but the package does not export them yet.

## Text Measurement

Labels are measured with a uniform monospace advance of 0.6 em per character. Wide characters take 1.2 em and zero-width characters take none.

Measurement needs no canvas, font tables, or DOM. A diagram compiled in Node is byte-identical to the same diagram compiled in a browser.

## Theme Variables

The SVG reads its colors, font, corner radius, and stroke width from `--melee-*` custom properties, with monochrome defaults. Setting `--melee-bg` and `--melee-fg` themes a whole diagram. [Theming](/guides/theming) lists every property.

```mermaid
pie title Series shades
  "series 1" : 40
  "series 2" : 30
  "series 3" : 20
  "series 4" : 10
```

Chart series default to shades between the foreground and background, so charts stay monochrome in both schemes.

## Inert Output

Output follows Mermaid's strict security level. Every authored string is escaped, and the SVG holds no scripts, event handlers, or external references.

Inserting compiled SVG with `innerHTML` is therefore safe, which is all [`mount`](/api/melee/mount) does.
