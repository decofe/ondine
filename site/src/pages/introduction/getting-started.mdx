# Getting Started

Compile Mermaid diagrams to SVG ahead of time and mount them with a 210-byte runtime.

## Overview

Melee renders Mermaid source to monochrome, monospace SVG. A Rust compiler parses, lays out, and draws each diagram at build time, so pages ship SVG markup instead of a diagram renderer.

```mermaid
flowchart LR
  source[diagram.mmd] --> compiler[Melee compiler]
  compiler --> svg[SVG]
  svg --> page[Page]
```

The compiler runs through the Vite plugin, the `melee` CLI, the Node API, an image Worker for Markdown hosts, and, when a page must compile at runtime, a WebAssembly module in the browser.

## Install

Install Melee with the project's package manager.

> [!NOTE]
> Melee is not published to npm yet. The commands below apply once the first release ships.

:::code-group

```sh [pnpm]
# Adds Melee to the project
pnpm add melee
```

```sh [npm]
# Adds Melee to the project
npm install melee
```

```sh [yarn]
# Adds Melee to the project
yarn add melee
```

:::

## Setup

Choose the integration that matches the build. Each one runs the same compiler and produces the same bytes.

<Tabs>
<Tab title="Vite">

Add the plugin to `vite.config.ts`. Imports of `.mmd` and `.mermaid` files then compile at build time.

```ts title="vite.config.ts"
import { defineConfig } from 'vite'
import { melee } from 'melee/vite'

export default defineConfig({
  // Compiles .mmd and .mermaid imports to SVG
  plugins: [melee()],
})
```

Import a diagram and mount it. The default export holds the SVG, its size, and the detected type.

```ts title="main.ts"
import { mount } from 'melee'
import flow from './flow.mmd'

// Inserts the precompiled SVG into the element
mount(document.getElementById('flow')!, flow)
```

</Tab>
<Tab title="CLI">

Render Mermaid files to SVG files beside them, or into a separate directory.

```sh
# Writes flow.svg next to flow.mmd
npx melee flow.mmd

# Writes every diagram into public/diagrams
npx melee diagrams/*.mmd --out-dir public/diagrams
```

With no files, the CLI reads standard input and writes SVG to standard output.

```sh
# Pipes Mermaid in and SVG out
echo 'flowchart LR; A --> B' | npx melee > flow.svg
```

</Tab>
<Tab title="Node">

Call `render` from a build script, a server, or a static site generator.

```ts title="build.ts"
import { render } from 'melee/compiler'

// Returns the SVG document with its size and diagram type
const { svg } = render('flowchart LR\n  A --> B')
```

The compiler module loads on the first call, and later calls reuse it.

</Tab>
</Tabs>
