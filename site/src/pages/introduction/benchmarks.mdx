# Benchmarks

Render speed and download size of Melee, Pele 1.6.0, and Mermaid 12.1.0, each in its best measured configuration. Colors compare each library with Melee.

Every library rendered all 612 vectors across 33 diagram types in headless Chromium 141, at `1c9f5d6` on a 4-core Intel Xeon at 2.10 GHz. [`bench/comparison.md`](https://github.com/wevm/melee/blob/main/bench/comparison.md) holds the full report, and `pnpm bench:compare` reproduces it.

## Mount Speed

Warm render is the average time per diagram over all 612 vectors once each library is loaded. Cold render runs from loading the library in a fresh page until its first diagram renders, averaged over the 33 types.

:::benchmarks
| Render | Melee | Pele | Mermaid |
| --- | --: | --: | --: |
| Warm | 54.9µs | 151µs | 36.8ms |
| Cold | 34ms | 55.6ms | 300ms |
:::

Melee's warm render uses its speed-optimized module, and its cold render the size-optimized module for the diagram type. Pele loads through `pele/lazy`, and Mermaid renders with `mermaid.render`.

## Diagram Size

Bytes a page downloads to display diagrams of every type. Melee compiles diagrams ahead of time, so a page ships only the `melee` runtime that mounts them. Pele and Mermaid ship their renderers, measured as minified esbuild bundles.

:::benchmarks
| Bytes | Melee | Pele | Mermaid |
| --- | --: | --: | --: |
| Gzip | 127 | 248064 | 1506327 |
| Brotli | 93 | 200236 | 1252410 |
:::
