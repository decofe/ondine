# melee

Mount precompiled diagrams in the browser without the compiler.

The root `melee` entrypoint is 210 bytes gzip and imports nothing from the compiler. It inserts SVG that `melee/vite`, the CLI, `melee/compiler`, or the image Worker produced ahead of time.

```ts title="main.ts"
import { mount } from 'melee'
import flow from './flow.mmd'

// Inserts the precompiled SVG
mount(document.getElementById('flow')!, flow)
```
