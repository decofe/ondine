# melee/remark

Compile Mermaid fences in Markdown and MDX to SVG at build time.

`melee/remark` exports one remark plugin. It compiles with the same module as `melee/compiler` and works wherever remark runs, such as `@mdx-js/rollup` in Vite. The [Vite](/guides/vite#compile-markdown) guide covers setup.

```ts title="vite.config.ts"
import mdx from '@mdx-js/rollup'
import { defineConfig } from 'vite'
import { remarkMelee } from 'melee/remark'

export default defineConfig({
  // Compiles Mermaid fences in .md and .mdx files
  plugins: [mdx({ remarkPlugins: [remarkMelee] })],
})
```
