# Melee

Melee renders Mermaid diagrams to monochrome, monospace SVG. A Rust compiler parses, lays out, and draws each diagram, and runs in browsers and Node through WebAssembly.

> [!NOTE]
> Melee is being rewritten. [`.agents/plan.md`](.agents/plan.md) tracks progress. The previous prototype lives on the `poc` branch.
